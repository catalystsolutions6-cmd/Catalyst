# Catalyst marketplace

Multi-vendor tech marketplace by [Catalyst Solutions](https://www.catsols.com). Shops from Lahore's
tech markets (Hafeez Center, Hall Road) get a virtual shop; their products appear on one storefront.
Customers never see which shop sells an item; the admin does.

| Folder | What it is |
|---|---|
| [`web/`](web/) | Storefront, admin panel and API (Next.js, Prisma, Tailwind). See `web/README.md`. |
| [`shopkeeper-app/`](shopkeeper-app/) | Android app for shopkeepers: snap a photo, AI fills in the listing (Expo / React Native). See `shopkeeper-app/README.md`. |

The brand name is a placeholder ("Barq"), set in `web/src/lib/brand.ts` and `shopkeeper-app/src/brand.ts`.
